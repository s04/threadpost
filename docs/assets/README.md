# Repository artwork

- `logo.svg`: scalable Threadpost conversation mark.
- `banner.svg`: README header using the same mark and product colors.
- `inbox.png`: actual admin UI, captured at 1440 × 960.
- `widget.png`: actual mobile widget, captured at 390 × 844.

The SVG artwork is original to this project and covered by the repository's MIT
license. Screenshots were captured from a local `CONNECTOR=demo` instance with
fictional people and messages. They contain no production data or credentials.
Retake screenshots against a fresh local demo database when the interface changes;
do not capture a connected production inbox.

The architecture diagram is maintained as Mermaid source in the root README so
GitHub can render it and contributors can edit it without a graphics tool.
