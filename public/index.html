A self-hosted website chat bridge

Turn a website visit into a real conversation.

Threadpost adds a focused chat window to your site and keeps replies in one practical inbox. Try the live widget in the corner.

01 One script. Your server. Your conversations.

How it works

A short path from page to reply.

  1. 01Add the widget

    Place one script tag on the pages where visitors should reach you.

  2. 02Receive a message

    Each visitor gets a private conversation authenticated in their browser.

  3. 03Reply from the inbox

    Use Threadpost’s admin view to read the thread and write back.

Installation

Small enough to understand.

The widget is plain JavaScript with an isolated Shadow DOM interface. Point it at the Threadpost server that serves it and identify your site.

<script src="https://your-threadpost.example/widget.js"
  data-site="your-site"
  data-title="Chat with us" defer></script>
