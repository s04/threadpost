Telegram setup instructions
  1. Create a bot with @BotFather and copy its token.
  2. Create a private group and enable Topics in its settings.
  3. Open Group info → Edit / Manage Group → Administrators → Add Administrator. Search for the exact bot username shown by BotFather, select your bot, enable Manage Topics, and save. Menu names vary between mobile, desktop, and web.
  4. Find the group’s numeric chat ID and each operator’s numeric Telegram user ID.

Threadpost cannot discover these IDs for you. Only people whose numeric IDs you enter can send operator replies.

“Telegram could not access that group” or “chat not found”? Check the chat ID, then add the same bot whose token you entered to that group using the administrator steps above. Creating a bot in BotFather or messaging it privately does not add it to your group. Save its permissions, then click Connect Telegram again.

How to find your private forum chat ID

Open your private group with Topics enabled, enter a topic such as General, and find a message inside it. Open the menu on the message bubble, not on the topic name or group title.

  • Mobile (Android / iPhone): Long-press the message bubble and choose Copy Message Link or Copy Link. If long-press selects the message, look in the selection toolbar’s ⋮ / More menu. On Android, a single tap on the bubble may open the message menu instead.
  • Desktop (Windows / Mac / Linux): Right-click the message bubble (Control-click on Mac also works), then choose Copy Message Link or Copy Link.
  • Web: Open Telegram Web, enter the group and topic, then right-click the message bubble and choose Copy Message Link or Copy Link. On a touch device, long-press to open the message menu.

Convert the copied link into a chat ID:

  1. In a link such as https://t.me/c/1234567890/12/34, take the first number after /c/: 1234567890.
  2. Put -100 before that number and paste -1001234567890 into the field above.

Ignore the later topic and message numbers. Use a message link, not a t.me/+… invite link. If the option is missing, check that Topics is enabled and try an ordinary text message inside a topic. Menu wording varies by Telegram version; try Desktop or Web if your mobile app does not show it.

Official Telegram references: message link format and Bot API group ID format.
